按下面的精修原则精修当前正文。

做法：先对照原则逐条检查当前正文，找出违规处；再只改违规处，输出精修后的完整正文。检查过程不要写出来，只输出正文。

底线：
- 情节、事件顺序、人物关系、对白的意思保持不变；不新增情节，不删掉推进剧情的信息。
- 正文里的 HTML、状态栏、代码块和固定格式原样保留，只改其中的叙述文字。
- 没问题的句子不动；篇幅与原文相近，不为凑字数扩写。
- 改法要多样：避开一个套话时，不要换成另一个套话。

# 一、句式

- 不用“不是A，是B”“并非A，而是B”“不像A，更像B”这类对照句式（角色对白里的口语除外）。
- 不用“如此……以至于……”“当……的时候”“取而代之的是”，不写先果后因的倒装句。
- 不用破折号“——”，改成逗号、句号或拆句。
- 不连续写三句长度相近、结构相同（主谓宾）的句子，要长短错落。
- 名词前的修饰语不超过两个；少用被动句。

# 二、动作

- 同一个动作只写一次，不反复拆解（压下去、弹回来、又压下去）。
- 动作场面用具体动词推进；日常场景的动作控制在三个以内。
- 一个场景动作最多中断一次，中断处补一句人物当下的念头。
- 小动作（撩头发、摸鼻子、舔嘴唇）最多一个。
- 删掉套路动作：攥紧又松开、指节泛白、喉结滚动、眼眶泛水光、嘴角扯出弧度、叹气。
- 骨骼描写最多一次；不用医学词（表皮、角质、毛细血管、痉挛、心率）。

# 三、视角与心理

- 写配角的感知用“看到、听到、感觉到”，不用“目光扫过”“映入眼帘”。
- 配角不写心理活动，情绪通过动作、语言、表情外显。
- 不写总结和下定义的句子：他终于明白了、这意味着、气氛缓和下来、他意识到、才意识到、忽然明白、终于懂了。让读者自己看出来。

# 四、对白与语言

- 对白后不写话语余波：这句话落下、话音刚落、说完这句、话说完、声音散开。
- 对白后不加自我解释的短句：是实话、不逞强、不解释、不废话。
- 不描写气音、音调、尾音（话尾带着一丝气音、尾音往上翘）。
- 叙述自然用口语连接词（就、便、倒是、也、还、又、才）和口语短语（怪冷的、挺大的）。
- 不堆抽象大词、空泛形容、翻译腔长从句、公文套话；不为显得高级而绕句、乱用典故。
- 不写递增数数式排比（一股、两股、三股；一步、两步、三步）。

# 五、环境与节奏

- 过渡性的环境描写不超过三句；不逐项罗列材质；删掉对剧情和情绪都没用的环境描写。
- 开头不要固定先写环境；结尾停在动作、对白或离场上，不以环境描写收尾。
- 转场写光线、声音、温度的具体变化，不用“气氛”“空气”这类抽象词。
- 少用“一下、一会儿、一声、一点、一阵”这类“一+量词”的短语，全文尽量不超过三处。
- 不用“再……就……”的拖延句式。
- 不用“x了x”的叠词：看了看、想了想、扯了扯、拍了拍、摸了摸、眨了眨、顿了顿等，改成单个动词或换说法。
- 少用“那张、那件、那双、那条、那片”这类“那+量词”的指代，能直接说名字或省掉就省掉。
- 结尾不写“在等/等着/等待某人做某事”。

# 六、内容

- 人物：言行、情绪反应、说话腔调（口癖、用词、语速）符合各自的人设、出身、年龄与经历；不知道不该知道的事；对不同人的态度符合彼此关系。有违背的就改回符合人设的说法。
- 剧情：与上一轮因果衔接自然，行为有动机，情绪有来源。
- 环境：保留的环境描写要服务情绪或剧情，至少有一处视觉以外的感官（声、味、触、温度）。
- 玩家：不替玩家角色行动、说话或推测其内心；当前正文若有越界，删掉越界部分。结尾给玩家留出明确的回应入口（要选择、回答或行动的节点）。
