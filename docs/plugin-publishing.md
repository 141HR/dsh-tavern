# 插件开发：发布与一键安装

## 用户怎么装

用户打开酒馆 → **设置 → DSH Tavern → 插件**，粘贴你的 GitHub 仓库地址，点「安装」，刷新页面就能用。连不上 GitHub 时，用户从仓库页面下载 ZIP，在同一处点「上传 ZIP」。

装好后，插件列表会显示「已加载 / 刷新后生效 / 加载失败（附原因）」。从 GitHub 装的插件可以一键更新；删除时插件文件夹会移到 `plugin-backups` 留底。

## 能一键安装的插件

- **仓库就是插件文件夹**：根目录（或任意一层）有 `package.json` 和宿主入口。插件文件夹怎么写，见[接口参考](plugin-api.md)的「快速开始」。
- **不依赖 npm 包**：`dependencies` 为空。确实要用某个库，就把用到的代码打包进插件，或连同 `node_modules` 一起提交；否则安装时会提示「依赖 npm 包，暂不支持一键安装」。
- **写上 `version` 和一句 `description`**：用户在插件列表里看到的就是它们。
- **设置和数据不要只存在插件文件夹里**：更新会整体替换文件夹，旧版只留在 `plugin-backups`。用 Tavern 提供的存档数据接口，或存到浏览器本地。

## 版本与更新

- 有 Release 时，一键安装和「更新」都取**最新 Release**；没有 Release 时取默认分支的最新代码。
- 想让用户装稳定版本，就发 Release（打个 tag 即可）；默认分支可以照常开发。
